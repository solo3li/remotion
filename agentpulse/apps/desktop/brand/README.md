`mark*.svg` 是 2026-08-22 用 `minimal-logo-design` skill 做的三轮尝试，**都没通过自查，不要用**。

## 试过什么、为什么不行

1. **一叠不齐的文字行，其中一行留缺**（概念：记录里有个开口在等你）
   → 读成"文字对齐"图标或骨架屏占位图。而且"文字行"本身就是通用文档图标，是另一种行业陈词。
2. **实心方 + 描边方，右缘留一个开口**（概念：平级同事，一个敞着口在等你）
   → 读成字母组合 `OC`。
3. **同上，缺口收成细缝、间距收紧**
   → 还是 `OC`，40px 下糊成一团。

## 结论

**图形语汇选错了**：方块是通用 UI 构件的形状，而方形边缘上任何开口都会被读成字母。概念本身（在场 + 一个等着被补完的缺口）站得住，但要换载体。

下一轮换**定制字标**路线：把 `agentpulse` 按严格模块网格构造，主记忆动作只留一个。不要再回到"两个方块"。
